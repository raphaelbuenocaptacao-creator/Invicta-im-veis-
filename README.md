# Invicta Imóveis

Site e PWA do corretor Ivan Melo, com atuação em São Paulo.

## Recursos
- Layout premium responsivo
- Catálogo de imóveis com filtros
- Favoritos locais
- Regiões em destaque
- Formulário de captação de leads
- PWA instalável e cache offline
- Estrutura pronta para receber fotos e dados reais dos imóveis

## Personalização pendente
Substituir as imagens demonstrativas pelas fotos oficiais, cadastrar telefone/WhatsApp, CRECI, endereço/área de atuação detalhada e informações reais dos imóveis.

## Publicação
Projeto estático compatível com GitHub Pages, Vercel, Netlify e hospedagens similares.
